The CN105 connector on Mitsubishi air conditioners allows communication with the indoor unit via a serial connection. This interface uses 5 V TTL (Transistor-Transistor Logic) levels, whereas modern microcontrollers such as the ESP32-C3 operate with 3.3 V logic levels.

The ESP32-C3 is not designed to receive 5 V directly on its GPIOs: its maximum theoretical input voltage is 3.6 V. In theory, therefore, directly connecting the ESP32-C3 GPIOs to the CN105 connector does not comply with the microcontroller's electrical specifications. In practice, however, this configuration works and has been proven in the field: in my case, more than 1,300 CN105-2HA controllers have already been sold using this configuration, with no reported cases of damage to the ESP32 related to logic levels. In addition, there are probably thousands of other individual maker projects using a direct connection between the CN105 and an ESPxx.

In reality, level shifting is only necessary in the CN105 → ESPxx direction: this is the direction in which the signal, which can reach approximately 5 V, is applied directly to the ESP32 GPIO, whose input is theoretically limited to 3.6 V maximum. In the ESPxx → CN105 direction, the 3.3 V signal generated by the ESP32 is recognized by the CN105 interface as a valid logic level, so there is no need to convert it to 5 V.

To implement level shifting in the CN105 → ESPxx direction, it is possible to use an integrated circuit specifically designed for logic level conversion, as presented in Echavet's GitHub project. However, this solution is difficult to implement in the CN105-2HA, as it would require a major redesign of the current module. Another, much simpler solution to integrate is to use a voltage divider made of two resistors on the TX signal coming from the CN105 connector. This voltage divider reduces the signal voltage before it reaches the ESPxx GPIO, so that the ESPxx receives a voltage of approximately 3.3 V, compatible with its electrical specifications.

This is the second solution that I can implement upon request.
